# Digital Agency Design System snippets

These components are copied from the [official React code snippets](https://github.com/digital-go-jp/design-system-example-components-react) at the commit in `UPSTREAM_COMMIT`. The upstream license is in `LICENSE` (MIT). They are source snippets, not an npm component package. The site keeps the upstream component APIs and uses the official `@digital-go-jp/design-tokens` and `@digital-go-jp/tailwind-theme-plugin` npm packages for styling.

Included components: `Button`, `Breadcrumbs`, `Disclosure`, `Heading`, `Link`, and their `Slot` dependency. Keep local changes to compatibility fixes and document them here when updating upstream. The site's layout and dark-theme color mapping live outside this directory.
